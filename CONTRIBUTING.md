# Contributing to MQTT Code

First off, thank you for considering contributing to MQTT Code! It's people like you that make this extension better for everyone.

## Where do I go from here?

If you've noticed a bug or have a feature request, please [open an issue](https://github.com/WhiteCloudCode/mqtt-code/issues)! It's best if you search the existing issues first to see if someone else has already reported your problem or requested your idea.

## Setting up for Local Development

1. Fork and clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run compile` to build the extension.
4. Press `F5` in VS Code to launch the Extension Development Host.

## Code Style

- The project is configured with `cspell` and `eslint`. 
- Please run `npm run lint` before committing to ensure everything adheres to the style guide and spelling dictionary.
- We use `prettier` for code formatting. Run `npm run format` to auto-format your code.

## Submitting a Pull Request

1. Create a new branch from `main` (e.g., `feature/my-awesome-feature` or `bugfix/issue-123`).
2. Make your changes and write tests if applicable.
3. Ensure the test suite passes by running `npm run test`.
4. Push to your fork and submit a Pull Request.
5. Provide a clear and comprehensive description of the changes in your PR.

Thank you!
